# مزامنة مخزون بحبح — من برنامج المحل إلى الموقع

الأداة دي بتربط برنامج المحل **Simple Assistant** بموقع بحبح: بتقرأ أسعار
ومخزون الأصناف من قاعدة بيانات البرنامج وترفعها لجدول `warehouse_products`
في Supabase، فالموقع يعرض التوفر الحقيقي ويبحث بالباركود من نفس المخزون.

## الأمان الأول

- الأداة بتفتح قاعدة برنامج المحل **قراءة فقط** (`mode=ro`) — مستحيل تكتب
  فيها أو تبوظ أي حاجة في شغل المحل.
- مفتاح الرفع (service role) **مش مكتوب في أي ملف** — بيتحط مرة واحدة في
  متغير بيئة على كمبيوتر المحل وخلاص.
- الأداة آمنة للتشغيل المتكرر: نفس الصنف بيتحدث مكانه (upsert) ومفيش تكرار.

## الإعداد — مرة واحدة بس

1. **ثبّت Python 3** على كمبيوتر المحل من python.org (وعلّم على
   "Add Python to PATH" وانت بتثبت).
2. **انسخ مجلد `inventory-sync`** ده كله لأي مكان على الكمبيوتر
   (مثلاً `C:\bahbah-sync`).
3. **شغّل ملفات الـ SQL** دي في لوحة Supabase (SQL Editor) بالترتيب، لو لسه
   ما اتشغلتش:
   `warehouse-seed.sql` ثم `upgrade-2026-11-19-warehouse-sync.sql`
   (الأول بينشئ الجدول، والتاني بيجهزه للمزامنة والقراءة العامة).
4. **اعمل ملف `config.json`** جنب السكربت (انسخ `config.example.json`
   وسمّيه `config.json`) وعدّل فيه سطرين:
   - `pos_db_path`: مسار ملف قاعدة بيانات برنامج المحل على الكمبيوتر ده
     (الملف اللي البرنامج بيحفظ فيه بياناته — اسمه غالباً `pharmacy.db`).
   - `supabase_url`: رابط مشروع Supabase (موجود جاهز في المثال — بدّله لو
     بتجرب على مشروع التجربة staging).
5. **حط مفتاح الرفع مرة واحدة**: افتح CMD كمسؤول واكتب:
   ```
   setx BAHBAH_SERVICE_KEY "حط هنا مفتاح service role من إعدادات مشروع Supabase"
   ```
   (المفتاح من: Supabase Dashboard → Project Settings → API → service_role)
   وبعدها اقفل أي نوافذ CMD مفتوحة.
6. **جرّب تشغيلة تجريبية** من غير رفع: دوس مرتين على `run_sync.bat` بعد ما
   تضيف `--dry-run`؟ أسهل: افتح CMD في المجلد واكتب
   `py -3 sync_inventory.py --dry-run` — هيطبع عدد الأصناف وعينة منها.
7. **التشغيل الحقيقي**: دوس مرتين على `run_sync.bat`. هتلاقي النتيجة في
   `sync.log` (اتقرأ كام صنف واترفع كام).

## التشغيل التلقائي (اختياري — من غير أي تدخل يومي)

من **Task Scheduler** في ويندوز:

1. Create Basic Task → الاسم: `Bahbah Inventory Sync`.
2. Trigger: Daily، وعلّم "Repeat task every: 15 minutes" لمدة 24 ساعة.
3. Action: Start a Program → اختار `run_sync.bat` من مجلده.
4. خلاص — المزامنة هتشتغل لوحدها كل ربع ساعة وانت مش محتاج تعمل حاجة.

## لو حاجة وقفت

- راجع آخر سطور `sync.log` — كل تشغيلة بتسجل نتيجتها وسبب أي فشل.
- "BAHBAH_SERVICE_KEY is not set": اعمل الخطوة 5 واقفل النوافذ وافتح من جديد.
- "ملف قاعدة بيانات المحل مش موجود": راجع مسار `pos_db_path` في `config.json`.
- أخطاء من Supabase فيها `sync_key`: معناها ملف
  `upgrade-2026-11-19-warehouse-sync.sql` لسه ما اتشغلش (خطوة 3).

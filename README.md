# صيدلية بحبح

تطبيق ويب (PWA) لصيدلية بحبح في ديروط: كتالوج ~1550 صنف، بحث، سلة، وإرسال الطلب على واتساب. الباك إند على Cloudflare Workers + D1.

- **للمطوّرين وأدوات الـ AI:** ابدأ بـ [CLAUDE.md](./CLAUDE.md).
- **تشغيل محلي:** انسخ `.dev.vars.example` إلى `.dev.vars` ثم `npm install && npm run dev`.
- **فحص:** `npm test`.
- **النشر:** خطوات أول مرة في CLAUDE.md (قسم "نشر").

## تعديل شغل يومي
- **أسعار ومخزون:** من لوحة الإدارة `/admin/` (بعد ربطها بالسيرفر) أو `PUT /api/admin/products/:id`.
- **رسوم التوصيل ورقم الواتساب:** `DLV` و`CFG` في أول `<script>` داخل `public/index.html`.
- **بعد أي تعديل في الواجهة:** غيّر رقم `V` في `public/sw.js` عشان العملاء ياخدوا التحديث.

# صيدلية بحبح — Bahbah Pharmacy

تطبيق متكامل لصيدلية أونلاين بهوية بصرية مبنية على **اللوجو الرسمي الجديد**: أدوية، فيتامينات، عناية بالبشرة، مستلزمات الأم والطفل، أجهزة طبية، وعناية شخصية — بواجهة عربية/إنجليزية كاملة (RTL/LTR)، متوافقة 100% مع الموبايل، و**جاهزة للتثبيت كتطبيق (PWA)** وللنشر السريع على **Cloudflare Pages**.

**الموقع:** جمهورية مصر العربية – محافظة أسيوط – مركز ديروط – منطقة تقسيم أبو جبل – خلف مساكن الضباط | **الهاتف:** 0101 150 0166+ / 0155 253 3484+ | **خدمة التوصيل:** واصلي (أسطول بحبح)

---

## التشغيل السريع

### المتطلبات
- Node.js 18 أو أحدث (أو Bun 1.1+)

### خطوات التشغيل

```bash
# 1) فك الضغط والدخول للمجلد
cd bahbah-pharmacy-app

# 2) تثبيت المكتبات
npm install        # أو: bun install

# 3) تشغيل التطبيق
npm run dev        # أو: bun run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

### بناء نسخة ثابتة للنشر (Cloudflare Pages / أي استضافة ثابتة)

```bash
npm run build      # ينتج مجلد out/ جاهز للرفع مباشرة
```

- الإعداد مفعّل داخل `next.config.ts`: `output: "export"` + صور غير محسّنة (static export)
- ارفع مجلد `out/` على Cloudflare Pages وستحصل على سرعة فتح أقل من ثانية
- **PWA جاهز:** `manifest.webmanifest` + أيقونات 192/512 — يثبَّت على شاشة الهاتف من قائمة المتصفح «إضافة إلى الشاشة الرئيسية»

## الميزات الكاملة

### 00) آخر تطويرات الشاشة الرئيسية (التحديث الأخير — كله شغال ومُختبَر)
- **ركن الجيم عند بحبح (GymZone):** قسم غامق فخم في نص الرئيسية — بيلم كل حاجات الجيم من المخزن الحي، مقسّم بالهدف: **الكل / تسمين وتضخيم / تخسيس وتنشيف / قوة وأداء / بداية صح** — كل هدف بفلتر منتجاته بتاعه، مع **شارة مخزون حي** بتقول كام منتج متاح دلوقتي من إجمالي 10، وسكرولر أفقي بكروت المنتجات الحقيقية + زر «شوف كل حاجات الجيم» بيفتح الكتالوج على قسم الجيم مباشرة
- **شريط الشحن المجاني الحي في الرئيسية:** جملة إعلانية مصريّة بتتحدث لحظيًا مع محتوى العربة — «التوصيل ببلاش للطلبات فوق 300 جنيه — كمّل عربيتك» ← «باقي 10 جنيه على 300.. وتحصل على توصيل مجاني» ← «مبروك عليك! طلبك ده توصيله مجاني» — الأرقام بتظهر في كبسولات برتقالية، والشريط بيتحول للأخضر لما تحقق الهدف، **والهدف يتظبط من لوحة الإدارة › الإعدادات (0 = إيقاف الميزة)**
- **سلايدر إعلانات نوون-ستايل بنر كبير + 4 بلاطات جانبية:** عداد تنازلي حي، كبسولة كود خصم BAHBAH10 بضغطة نسخ + توست تأكيد، شرائح دعائية جديدة (ركن الجيم / صندوقك الشهري / عروض بتحرق / واصلي / العناية بالبشرة / أم وطفل)، ken-burns زوم، سحب باللمس، وأشرطة قصص (story bars)
- **كل نصوص الرئيسية بالمصري الإعلاني:** «محتاج أمانة.. وبدي معاك في كل خطوة» / «اتفرج على الأقسام» / «الأكثر طلبًا عند الناس» / «شوف كل حاجات الجيم» — ونبرة واحدة من الهيرو للفوتر
- **إصلاح سكريبت البناء:** `npm run build` بقى يطابق static export (`output: "export"`) — بينتج `out/` جاهز للنشر من غير أي خطوة نسخ إضافية

### 0) رعاية بحبح — صناديق العلاج الشهري (أحدث تحديث)
- **باقات هدف حقيقية مش كلام فاضي:** 4 صناديق جيم حقيقية — **صندوق التضخيم والتسمين** (ماس جينر + كرياتين + ملتي فيتامين + شاكر) / **صندوق التخسيس والتنشيف** (كارنيتين + حارق دهون + واي بروتين + ملتي فيتامين) / **صندوق القوة والأداء** (كرياتين + بري وركاوت + BCAA + شاكر) / **صندوق البداية الصح** (واي + كرياتين + بروتين بار + شاكر) — وكل صندوق بأسعار حقيقية أقل من شراء الأصناف لوحدها
- **قسم «تغذية الجيم» جديد في الكتالوج:** 10 منتجات احترافية (كرياتين مونوهيدرات، واي جولد ستاندرد، ماس جينر، BCAA 2:1:1، إل كارنيتين 3000، حارق ثيرموجينيك، بري وركاوت، ملتي فيتامين رياضيين، بروتين بار، شاكر بحبح 700مل) — كل منتج بصورة packshot مولّدة بالذكاء الاصطناعي ووصف تسويقي مصري
- **المخزون مربوط بكل حاجة:** كل طلب **بيخصم من المخزن لحظيًا** — السلة بتمنع تزيد عن المتاح (زر + بيتقفل) وتحذّر «باقي X بس في المخزن» أو «خلص من المخزن» — كروت الصناديق بتورّي **حالة المخزون الحية** (مخزونه كامل — يتحرك فورًا / الكميات محدودة — احجز بدري / بيتم تزويد المخزن) — والصور المصغرة جوه الصندوق بتفتح صفحة المنتج
- **الجيميفكيشن — «باقي كام على مجانًا»:** شريط تقدم احتفالي في السلة والدروار «باقي {x} بس.. والتوصيل علينا» ← لما توصل الهدف: «مبروك! خلصت الهدف والتوصيل علينا» — **والهدف (افتراضيًا 300 ج.م) بيتظبط من لوحة الإدارة › الإعدادات** والحساب بيتطبق تلقائيًا في السلة والكاشير والدراور
- **لف مصري شيك ودعائي:** كل نصوص صفحة العلاج الشهري والصناديق والسلة اتكتبت بالمصري المحترم («جهّز صندوقك دلوقتي» / «صندوقك اتشحن!» / «جيمر مشترك معانا»)
- **صور AI جديدة:** 10 packshots للمنتجات + صورة تصنيف الجيم (`scripts/gen-gym-packshots.mjs`)
- بطاقة عضوية راقية + معالج اشتراك بخطوتين + منشّئ صندوق ذكي + حاسبة توفير + صيدلك الشخصي + رحلة الشحنة — زي ما هي، وكلها اتحركت للصناديق الجديدة
- حماية الاشتراكات القديمة: ترقية تلقائية (Migration v3) — أي اشتراك قديم على خطة اتشالت بيتنضف تلقائيًا

### 0.5) توصيل أبسط وأسرع (تحديث checkout)
- **«استخدام بيانات آخر طلب» بضغطة واحدة** — الاسم والموبايل والعنوان والمنطقة والميعاد تتعبأ فورًا
- مناطق التوصيل بقت **قائمة منسدلة واحدة أنيقة** (مدينة ديروط ← القرى ← المحافظات) بسعر ووقت الوصول جنب كل منطقة + سطر توضيحي تحتها (الرسوم + حد الشحن المجاني + ETA)
- **«في أسرع وقت» هو الافتراضي** — المواعيد المحددة مخفية ورا زر «تحديد ميعاد معين» — الطلب بيتم في أقل خطوات
- الملاحظات بقت «اختياري» + طريقة الاستلام بقت مفتاح مضغوط (توصيل للباب / استلام من الفرع)
- **حماية من الطلب المزدوج:** الضغط المتكرر على «تأكيد الطلب» ما ينعش طلب فارغ تاني
- سلايدر الإعلانات: الشرائح المخفية بقت `inert` — مفيش زر لشريحة غير ظاهرة يشتغل بالغلط

### أ) خطة التطوير السابقة — محققة بالكامل في النسخة دي
| المحور | التنفيذ |
|---|---|
| توصيل ديروط بالقرى الحقيقية | 10 مناطق بأسماء قرى ونجوع مركز ديروط الحقيقية + تسعير من اللوحة |
| سهولة لكبار السن | «الوضع المريح» — خط أكبر + أزرار 48px+ + تقليل الحركة + تباين أعلى |
| لغة الطلب | كل «اشترِ / تسوق» اتحولت لـ «اطلب الآن» — كلمات أخف وأنسب للعميل |
| Cloudflare Pages | Service Worker للعمل بدون إنترنت + offline.html + _headers أمان وكاش |
| المخزن | صفوف غنية بالصور والأسعار والعروض والتصنيفات في بوابة الصيدلي |

### 1) واجهة العميل — بذوق الشركات الكبيرة (مطوّرة)
- **هيرو أولاً + شريط متحرك (Marquee):** ترتيب جديد للرئيسية — الهيرو بالشعار الرسمي أولاً مع عناصر عائمة متحركة، ثم **شريط ثقة متحرك لا نهائي** (توصيل 30 دقيقة · أصلي 100% · علاج شهري…)، ثم سلايدر الإعلانات — وظّبنا مكان الإعلان في مكانه الصح
- **سلايدر إعلانات احترافي (Ad Carousel):** 5 بنرات بصور إعلانية مولّدة خاصة بالصيدلية + طبقات تدرّج + نصوص عربية/إنجليزية + أزرار CTA، تشغيل تلقائي كل 5 ثوانٍ مع سهمين ونقاط مؤشرات وإيقاف عند التحويم — **ومتوافق 100% مع شاشات الموبايل بدون تعليق أو اختفاء**
- **لاندينج قوية:** هيرو بالشعار الرسمي المعزول بخلفية شفافة، شريط ثقة، إحصائيات، **تصنيفات بصور منتجات حقيقية**، عروض الأسبوع، الأكثر طلبًا، **كروت خدمات التوصيل (شحن سريع / واصلي / استلام من الفرع / شحن لكل مصر)**، نصايح الصيدلي، آراء عملاء، وبانرات وسط الصفحة
- **رعاية بحبح — العلاج الشهري (الميزة الأولى في التطبيق):** صفحة كاملة مستقلة `care.tsx` — هيرو متحرك + عدادات إحصائية، 6 خطط حسب الحالة المزمنة، بطاقة عضوية، معالج اشتراك، منشّئ خطة ذكي، حاسبة توفير، صيدلك الشخصي، رحلة الشحنة، أسئلة شائعة (Accordion) — + قسم بارز في الرئيسية + **تبويب «علاج شهري» في شريط التنقل السفلي** والهيدر والفوتر + إدارة الاشتراك الكاملة في الحساب وصفحة العلاج الشهري

### 2) الأدوات الطبية السريعة (تمييز بحبح)
- **الوضع المريح لكبار السن (جديد):** زر واحد في «أدوات طبية» — يكبّر الخط (20.5px+) ويكبّر كل الأزرار والحقول لـ 48px+ ويوقف الحركات الزخرفية ويزود التباين — محفوظ بين الجلسات، والتطبيق كله بيبقى أسهل في القراءة واللمس
- **فاحص التعارضات الدوائية:** اختار دوائين واعرف فورًا لو فيه تعارض (آمن / تحذير / خطر) بقواعد دوائية استرشادية
- **البحث الصوتي:** زر مايك داخل البحث — يعمل بالعربية (ar-EG) والإنجليزية عبر Web Speech API مع بديل آمن لو المتصفح لا يدعمه
- **رفع الروشتة بالكاميرا/الواتساب:** رفع صورة الروشتة بكود مرجعي تلقائي + زر **«إرسال عبر واتساب»** يفتح محادثة الصيدلية برسالة جاهزة
- **استشر الصيدلي الفوري:** زر عائم أخضر ثابت في كل الشاشات للوصول السريع للصيدلي المناوب

### 3) السلة والعروض (مطوّرة بالكامل)
- **سلة جديدة:** صور المنتجات الحقيقية (Packshots) + شريط تقدم متحرك نحو الشحن المجاني مع لمعة Shimmer + **حقل كود الخصم داخل السلة** + صف «وفّرت» بسعر ما قبل الخصم + إجمالي كل سطر + أزرار كمية بحركة ضغط
- **اقتراحات ذكية:** «عملاء بحبح بشّروا بيهم» — منتجات من نفس تصنيف السلة أو المفضلة تُضاف بضغطة
- **الشريط العائم الذكي للسلة:** يظهر أسفل الشاشة بمجرد إضافة أي منتج (العدد + الإجمالي + زر إتمام طلب سريع) — يختفي تلقائيًا في صفحات الدفع
- **محرك الكوبونات:** `BAHBAH10` (10% فوق 200) و `BAHBAH20` (20% فوق 500) و `DEIROUT15` (15% فوق 300) — تطبيق فوري في صفحة الدفع مع حساب التوفير ورسالة خطأ لو الكود غير صحيح أو الطلب أقل من الحد
- **الدفع بمنظومة توصيل كاملة حول ديروط — بأسماء القرى الحقيقية:** 10 مناطق: مدينة ديروط (10ج · 25د) / ديروط الشريف-كودية الإسلام-مسارة-سرحان (12ج · 30د) / **دشلوط** / **الحوطا الشرقية والغربية** / **النزلات** (نزلة عبد الله، نزلة ظاهر، نزلة بدوي، نزلة ساو، نزلة سرقنا، نزلة العوامر…) / **قرى الشروق** (أبو الهدر، أبو كريم، أمشول، شلش، عواجة، صنبو، باويط…) / **قرى الغروب** (الرياض، المطاوعة، المحمودية، المناشي، المندرة، قصر حيدر…) / أسيوط والمدينة الجديدة / صدفا-أبنوب-منفلوط-القوصية / باقي محافظات مصر (شحن شركات) — **منتقي المناطق في صفحة الطلب مقسوم مجموعات واضحة: مدينة ديروط ← قرى ونجوع مركز ديروط ← أسيوط والمحافظات**
- **تسعير التوصيل من لوحة التحكم:** عدّل سعر كل منطقة/قرية + وقت الوصول + حد الشحن المجاني — التغيير يظهر فورًا في صفحة الطلب + إيقاف/تشغيل أي منطقة
- **4 مواعيد توصيل** + كارت فرع ديروط + دعم الشراء كزائر + دفع عند الاستلام / إنستاباي / بطاقة

### 4) التتبع بنظام الشركات الكبيرة
- خريطة SVG مرسومة مع **سكوتر متحرك على المسار** يتقدم مع حالة الطلب + خط زمني بأربع مراحل + كارت المندوب بشعار **«واصلي — أسطول بحبح»** (الاسم + التقييم + اللوحة + اتصال + محادثة) + كود تسليم OTP + تقييم التوصيل + **محاكاة تحديث الحالة**

### 5) حسابات وصلاحيات — كل دور ليه بوابته
- **4 أدوار:** مريض / مندوب / صيدلي / إدارة — شاشة الدخول فيها اختيار نوع الحساب + **دخول سريع بضغطة لكل دور**
- **المريض:** يتصفح ويطلب ويتراكر — بياناته بتعبأ تلقائيًا في الشيك أوت
- **بوابة المندوب (`courier.tsx`):** شحنات النهاردة + عنوان كل عميل كامل + زر اتصال + **فتح الخريطة (Google Maps)** + المبلغ المطلوب تحصيله + أزرار «استلمت من الصيدلية» و«تم التوصيل» بتحدّث الطلب فورًا عند العميل والإدارة + حالة المندوب (متاح/مشغول/غير متصل) + مكاسب اليوم
- **بوابة الصيدلي (`pharmacist.tsx`):** بحث فوري في المخزون بالاسم/المادة الفعالة/الشركة + رصيد كل صنف + طلبات محتاجة تحضير بزر «تجهيز وتسليم للمندوب» + الروشتات الواردة (موافقة/رفض) + جداول **أقل من الحد الآمن** و**تنتهي خلال 90 يوم** + إعادة تعبئة مخزون بضغطة
- **حماية الصلاحيات:** أي بوابة فريق تفتح من غير الحساب المناسب بتظهر بوابة دخول آمنة — حسابات الفريق:
  - مندوب: `courier@bahbah.eg` · صيدلي: `pharmacist@bahbah.eg` — كلمة السر `123456`
- **بوابة كلمة سر للوحة الإدارة:** لوحة الإدارة ليها دخول خاص بكلمة سر مستقلة — الافتراضية **`2026`** (عرضة فوق حقل الدخول، وبتقدر تغيّرها من الإعدادات) — جلسة اللوحة محفوظة بين الجلسات + زر «قفل اللوحة»

### 6) حسابي — بسيط وقوي
- تسجيل دخول/حساب جديد بتحديد الدور (مريض/مندوب/صيدلي/إدارة) مع شارة الدور في الحساب + اختصار البوابة
- **طلباتي** بحالات الطلب + تتبع + **إعادة طلب بضغطة (1-Click Reorder)**
- **رعايتي الشهرية:** **بطاقة عضوية رعاية بحبح كاملة** (المستوى + الشحنة القادمة + عدّاد الأيام + التوفير + الإضافات) + إيقاف مؤقت/استئناف/إلغاء + **تغيير يوم الشحنة** + اختصار لمنشّئ الخطط
- المفضلة + بياناتي + **برنامج الولاء** بالنقاط والمستويات المحسوبة من سجل طلباتك الحقيقي

| **الإعلانات والبنرات** | تحكم كامل في بنرات الرئيسية: إظهار/إخفاء + **تعديل نصوص كل بنر (عنوان/وصف/شارة/زر) بالعربي والإنجليزي — التغيير يظهر فورًا في الرئيسية** + النقرات |
| العملاء | بحث + نقاط + VIP |
| التقارير | مبيعات وتصدير CSV |
| الإعدادات | الخط الساخن + فتح/غلق الصيدلية + قبول الطلبات + حد الشحن المجاني + **بيانات التواصل والعنوان (تتحدث فورًا في الفوتر وصفحة التتبع)** + **كلمة سر اللوحة** + **تعديل أسماء وأسعار خطط العلاج الشهري** + إعادة ضبط البيانات |

### 8) البنية التحتية — مستغلة Cloudflare Pages بالكامل
- **Static Export:** إخراج ثابت بالكامل — سرعة أقل من ثانية وثبات ضد الضغط
- **Service Worker (PWA):** التطبيق يشتغل **بدون إنترنت** — هيكل التطبيق cached، والصور والملفات cache-first مع تحديث خلفي، وصفحة **offline.html** براند كاملة لما الشبكة تقع
- **ملف `_headers`:** أمان (nosniff، X-Frame-Options، Referrer-Policy، Permissions-Policy) + كاش ذكي: الأصول سنة immutable، الصور شهر مع stale-while-revalidate — استفادة قصوى من حافة Cloudflare
- **PWA Ready:** manifest + أيقونات + ثيم لوني — تثبيت كتطبيق بدون متجر
- **حالة محلية دائمة (localStorage):** السلة والمفضلة والطلبات والكوبونات والاشتراكات وكل تعديلات اللوحة محفوظة بين الجلسات
- **أيقونات مخصصة:** عائلة أيقونات SVG مرسومة خصيصًا (خطي + دوتون) بالألوان الرسمية
- **نظام حركة متكامل:** ظهور تدريجي عند التمرير (Reveal/IntersectionObserver) + عناصر عائمة + لمعة + شريط متحرك + تدرّج نصي متحرك — مع احترام `prefers-reduced-motion`
- **صور منتجات واقعية:** 14 لقطة منتج Packshot مولّدة بالذكاء الاصطناعي للمنتجات المميزة (تظهر في الكتالوج وصفحة المنتج **والسلة والاقتراحات**)، مع سقوط تلقائي لأيقونة الدوتون للمنتجات الباقية

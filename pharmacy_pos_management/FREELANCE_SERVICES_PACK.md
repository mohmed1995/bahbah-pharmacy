# باقة إطلاق الخدمات للربح السريع (خمسات / كفيل / فيسبوك / Upwork)

---

## 📌 الخدمة الأولى: قاعدة بيانات ومنتجات الصيدليات والأدوية (جاهزة للتسليم فوراً)

### 🏷️ العنوان المقترح (خمسات / كفيل):
**توفير قاعدة بيانات كاملة للأدوية ومنتجات الصيدليات (Excel / SQL / JSON)**

### 📂 التصنيف:
- برمجة وتطوير > قواعد بيانات (أو) أعمال > إدخال بيانات.

### 💰 السعر المقترح:
- الخدمة الأساسية: 10$ إلى 15$ (أو 500 إلى 800 جنيه مصري).
- التطويرات (SQL Dump + صور المنتجات كاملة): +10$ إضافية.

### 📝 وصف الخدمة (انسخه والصقه كما هو):
```text
السلام عليكم ورحمة الله،

هل تؤسس موقع صيدلية إلكتروني، تطبيق توصيل أدوية، أو تبحث عن قاعدة بيانات جاهزة لبرنامج إدارة الصيدليات؟
أوفر لك قاعدة بيانات مهيكلة ومحدثة تضم أكثر من 1,500 منتج دوائي وتجميلي متوفر في السوق المصري والعربي بأعلى دقة وتنسيق.

ما تتضمنه قاعدة البيانات لكل منتج:
1. الاسم التجاري باللغة العربية والإنجليزية بدقة عالية.
2. التصنيف الطبي والنوع (Category).
3. الشكل الدوائي والتركيز (Form & Strength).
4. السعر الرسمي للمستهلك (Public Price).
5. روابط صور المنتجات بجودة عالية.
6. الرابط التعريفي والاسم القياسي (Slug & Normalized Name).

صيغ التسليم المتوفرة:
- ملف Excel جاهز للتصفح والفلترة.
- ملف CSV مهيأ للاستيراد المباشر في أي نظام.
- ملف JSON أو قاعدة بيانات SQLite جاهزة للمطورين والمبرمجين.

* متاح إرسال عينة مجانية (Sample) قبل الشراء لمعاينة الجودة وتوافق الحقول.
* متاح التخصيص أو إضافة أي حقول خاصة بناءً على طلبك.
```

## 📌 الخدمة الثانية: استخراج البيانات والملفات الطبية والروشتات بالذكاء الاصطناعي

### 🏷️ العنوان المقترح:
**تفريغ واستخراج بيانات الروشتات والملفات الطبية الورقية إلى Excel بالذكاء الاصطناعي**

### 📂 التصنيف:
- أعمال > تفريغ وإدخال بيانات (أو) ذكاء اصطناعي.

### 💰 السعر المقترح:
- 5$ لكل 10 إلى 15 صفحة / روشتة (مع إمكانية مضاعفة الكمية).

### 📝 وصف الخدمة:
```text
السلام عليكم ورحمة الله،

هل تمتلك دفاتر حسابات، استمارات عيادات، أو روشتات طبية مكتوبة بخط اليد وتريد تحويلها إلى ملفات إكسل منظمة دون عناء الإدخال اليدوي البطيء؟

أقدم لك خدمة تفريغ واستخراج البيانات المكتوبة بخط اليد والممسوحة ضوئياً (PDF / صور) باستخدام أحدث نماذج الرؤية الحاسوبية والذكاء الاصطناعي بدقة متناهية وسرعة فائقة.

ما ستحصل عليه في هذه الخدمة:
1. استخراج بيانات المرضى بدقة: (الاسم، السن، الهاتف، التاريخ المرضي، التشخيص، تفاصيل العلاج).
2. تفريغ الجداول المالية والزيارات: (تاريخ الجلسة، الإجراء، المدفوع، المتبقي).
3. ملف Excel منسق واحترافي بأعمدة واضحة مع إحصائيات للملفات.
4. مراجعة وتدقيق لغوي لضمان خلو الأسماء والأرقام من الأخطاء.

لماذا تختار هذه الخدمة؟
- سرعة تسليم فائقة (خلال ساعات قليلة للكميات المتوسطة).
- دقة قراءة خط اليد الصعب وغير الواضح.
- خصوصية وأمان تام لبيانات المرضى والمستندات.

* أرسل صفحة واحدة الآن لمعاينتها مجاناً والتأكد من الجودة قبل طلب الخدمة!
```

# نظام إدارة الصيدلية والكاشير الداخلي (POS & Pharmacy Management System)

هذا المجلد يحتوي على **نظام إدارة الصيدلية المستقل** (الكاشير، قواعد البيانات، السيرفرات، وأدوات المزامنة):

## محتويات النظام:
1. **شاشة الكاشير والباركود (POS)**:
   - `admin_pos.html`: شاشة الكاشير السريعة مع قارئ الباركود، البيع بالعلبة والشريط، وطباعة الفواتير.
2. **سيرفرات الباك إند وإدارة البيانات**:
   - `server_fast.py`: سيرفر Python خفيف وسريع على المنفذ `5050` لإدارة المخزون والبحث اللحظي.
   - `server.js`: سيرفر Node.js متصل بقاعدة بيانات `pharmacy.db` ورسائل واتساب ونظام التذكير.
   - `pharmacy.db`: قاعدة بيانات SQLite تحتوي على 1,500+ صنف من الأدوية وسجلات العملاء.
3. **أدوات المزامنة والكتالوج**:
   - `sync.js` و `scrape_full_catalog.py`: سكربتات مزامنة وجلب الأسعار والبيانات.
   - `products.json` و `products_catalog.json`: بيانات الكتالوج الكامل.

## طريقة التشغيل:
- لفتح الكاشير مباشرة: افتح ملف `admin_pos.html` في أي متصفح.
- لتشغيل سيرفر المخزون السريع:
  ```bash
  python server_fast.py
  ```
  ثم افتح: `http://localhost:5050`
